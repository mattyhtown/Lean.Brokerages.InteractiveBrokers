# Cursor MCP (examples)

Copy `mcp.json.example` to your user config or merge into [Cursor MCP settings](https://cursor.com/docs/context/mcp). **Do not commit real API keys.**

## Unusual Whales

1. Get an API key from [unusualwhales.com/settings/api-dashboard](https://unusualwhales.com/settings/api-dashboard).
2. Use either **hosted** (`unusualwhales`) or **local** (`unusualwhales-local` via `@unusualwhales/mcp`)—not both unless you need two connections.
3. Restart Cursor after changing MCP config.

Install the local plugin (optional): `~/.cursor/plugins/local/unusual-whales-mcp/` on this environment.
